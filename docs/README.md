# CUMARA - Plataforma de viajes compartidos

Prototipo Front-End navegable desarrollado para la Actividad 9. 
CUMARA es una aplicación web responsiva diseñada para coordinar viajes compartidos de forma comunitaria.

## Vistas
1. index.html - Inicio de sesión
2. registro.html - Registro de usuario
3. dashboard.html - Panel principal
4. buscar-viajes.html - Buscar viajes
5. detalles-viaje.html - Detalles del viaje
6. mis-viajes.html - Mis viajes
7. publicar-viaje.html - Publicar viaje
8. solicitudes-viaje.html - Solicitudes de viaje
9. mi-perfil.html - Mi perfil
10. notificaciones.html - Notificaciones
11. calificar-viaje.html - Calificar viaje

## Tecnologías utilizadas
- HTML5 semántico
- CSS3 con variables y diseño responsive
- JavaScript Vanilla para interacciones de demostración
- Git/GitHub
